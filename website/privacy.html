Privacy Policy

Secret Sanitizer is a privacy-first Chrome extension with a single narrow purpose: to prevent accidental disclosure of sensitive information when interacting with AI chat websites. All processing happens locally on your device — no data ever leaves your browser.

KEY POINT: Your secrets stay on your device. Always. No exceptions.

Data Processing

All data processing performed by Secret Sanitizer occurs entirely on your local device. The extension does not transmit, sync, upload, or share any data with external servers or third parties.

To do its job, the extension handles the following on your device only:

  • Text you paste into a protected site, and text you copy there, which it checks for placeholders and secrets
  • Anything that text contains, which can include passwords, API keys, card numbers and identification numbers such as Aadhaar or PAN. Masked values are kept only in the memory-only vault described below
  • The address of the current tab when you open the popup, to show its status

Local Storage Usage

The extension stores data only in your browser's extension storage:

  • Temporarily masked secret values in a memory-only vault (chrome.storage.session: never written to disk, deleted after 15 minutes or when the browser closes), used to restore originals when you unmask from the popup or copy AI responses via Smart Restore
  • Aggregate user statistics (e.g., total and daily count of blocked secrets)
  • User preferences, such as enabled or disabled detection patterns, custom websites and pause state (chrome.storage.local)
  • Values you chose not to mask, kept only as salted hashes that don't reveal the value (chrome.storage.local)

All stored data remains local to your browser and is never accessible outside the extension.

Permissions Used

Secret Sanitizer requests only the minimum permissions needed for its single purpose. None of them are used to send data anywhere:

  • storage — Saves user preferences and local statistics.
  • scripting — Injects lightweight content scripts to detect and mask secrets on AI chat pages.
  • alarms — Cleans up expired vault entries every 5 minutes, ends a timed pause on schedule, and checks for the weekly summary daily.
  • notifications — Displays an optional weekly summary notification (Sundays) showing aggregate counts only. It is off by default for new installs.
  • activeTab — Reads only the current tab's URL when you open the popup, to show whether the extension is active on that site and to offer adding or pausing it. No page content is accessed this way.
  • Host permissions — Limited to major AI chat domains (chatgpt.com, claude.ai, gemini.google.com, grok.com, and any sites you explicitly add).

Nothing Leaves Your Browser

Secret Sanitizer never sends us or anyone else:

  • Personally identifiable information
  • Browsing history or web activity
  • Clipboard contents or anything you paste
  • Financial, authentication, health, or location data
  • Analytics, telemetry, or usage data

No External Communication

The extension makes no network requests and does not communicate with any remote servers. No data is sold, shared, or disclosed to any third party.

Uninstall Page

When you uninstall, Chrome opens a static page on this site asking why you left. It contains no scripts or analytics and nothing about you is added to its address. Answering is optional and simply opens a public GitHub issue that you can review before posting.

Code Execution

Secret Sanitizer does not execute remote code. All scripts are bundled with the extension package and run locally within the browser.

Supported Websites

By default, Secret Sanitizer works on ChatGPT, Claude, Gemini, and Grok. You can add other AI chats or any custom website with explicit permission, and removing a custom website also gives up that permission.

Data Retention

Vault entries automatically expire after a short retention period (default 15 minutes) and are cleaned up by a periodic background task. Settings and statistics stay in your browser until you uninstall the extension. There is no external storage.

Your Rights

You control the data stored locally. From the extension's popup you can change or export your settings and delete vault entries and allowed values at any time. Uninstalling the extension removes everything, including statistics.
